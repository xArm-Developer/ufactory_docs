发布时间：2026.07.31

## 固件 V2.8.2
1. TCP 30000 端口增加夹爪/控制盒IO/机械臂IO,规划与实际TCP 加速度,六维力矩传感器使能状态上报。
2. TCP 30002 端口增加夹爪信息上报。
3. 笛卡尔在线规划(mode 7) 支持相对位置指令。
4. 兼容新力矩传感器（AI1500）
5. 优化xArm7逆解方案,支持可配置，优先使用保持手臂直立的解。

## Studio V2.8.2

1. 实时控制-末端执行器-Robotiq支持加速度和力调节。
2. 实时控制-末端执行器-Gripper G2和BIO G2 增加驱动版本和SN显示。
3. 实时控制-末端执行器-增加六维力矩传感器（AI1500）。
4. 实时控制-末端执行器-夹爪(不含Robotiq )支持3D显示开合。
5. 实时控制-3D 场景-增加仿真环境碰撞检测的开关和对应的功能。
6. 实时控制-轨迹录制-导入轨迹格式支持.traj。
7. Blckly- 末端工具-增加使用变量控制BIO Gripper G2和Robotiq Gripper 的代码块。
8. Blckly- 末端工具-增加获取末端执行器位置的代码块。
9. Blocly-外接设备-获取保存寄存器地址增加数据解析的选项[hex/int16/uint16]
10. Blockly-运动-增加TCP和关节的速度/加速度的变量控制代码。
11. Blockly-允许缩小的比例在当前基础上再缩小4x。
12. Python IDE-允许下载BlocklyToPython文件夹下的文件。
13. Gcode-增加示例文件/文件夹的下载功能。
14. 设置-运动参数-TCP设置-内置TCP参数增加新六维力矩传感器（AI1500)。
15. 设置-通用设置-高级设置-增加关节伺服模式线速度阈值修改入口。
16. 设置-通用设置-高级设置-机械臂停止状态清空IO兼容xArm 1305系列和850机械臂。
17. 设置-外界设备-力矩传感器-兼容新版(AI1500)六维力矩传感器。
18. 设置-外界设备-力矩传感器-增加示教启动力和力矩值设置。
19. 设置-外接设备-RS485-支持单独设置控制盒或机械臂末端的Modbus RTU与透传的超时时间。
20. 设置通用-辅助功能-3D模型分辨率与模型刷新率选项合并为3D模型高质量。
21. 报错处理-S20增加驱动类型查询，C39增加IC错误码查询。
22. 错误码处理-S17/S18/S20/S54：屏蔽对 0x0813 V16 的访问，规避并发读写 PVL 导致 S22 编码器配置错误的风险。

24. 错误码处理-S20：修复驱动类型为 0 时会持续查询 0x000C 地址的问题。
25. 其他-前端兼容wss请求。
